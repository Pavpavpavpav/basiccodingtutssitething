Basic CSS Guide

This part will teach you how to style your beginner HTML website with CSS



CSS is a programming language used to style HTML websites. It allows for the addition for colors and other elements instead of being plain white text on a white background.

This website uses basic CSS so it doesnt look like plain white text!


Editor Setup

Like HTML, many editors, including Visual Studio Code, can edit CSS code without any extensions, but you can install extensions for QoL (QoL is short for Quality of Life)


In order to edit CSS code, you must create a file in the same folder like you would do for HTML, just with .css (it is possible to do it all in one file but it is more organized in multiple). For the css to have effect on your website, you have to link it to the document using <link rel="stylesheet" href="inputcssfilehere"> (no closing tag is needed)

How to CSS

There are two main ways to apply CSS styling to HTML elements: by assigning it to a class or a whole element. If the selector starts with a . (.class1), it only applies to elements that have stated to be a part of that class (<p class="example">). Another way to style an element is to make the selector be a HTML tag, where every tag in the code will be affected by the style even if it isnt declared (p {} ) 



            p {
                (Style put here affects every p tag)
            }
            
            .example {
                (Style put here affects every HTML tag that puts it in the class="" section)
            }

It is also possible for a selector to only apply style to tags that happen to be inside another set of tags that are influenced by a specific class (.example p), used mostly with <div> tags, but that is a bit more advanced.

CSS Declaration list

The statements that influence the style of HTML are called Declarations. Below is a list of them that one might find useful when using CSS to style their first Website.


align-content
Makes the conent in a div be centered in it (can be used for centered text if the width of the div is the same of the website)
background-color
Changes the color of the background of an element, if used in the body tag, it can change the background color of the entire website
background-image
Sets the background to be a preset image instead of a solid color
border
Adds a border to the element it is applied to
border-color
Sets the color of the border of the element it is applied to
color
Sets the color of text inside the element it is applied to
font-family
Can be used to set the font of the text in an element, use an css extension that autocompletes the statements in order to be able to pick between a lot of them without manually searching
font-weight
Specifies the weight of the font (thickness). 600 is bold text
height
Specifies the height of an element
margin
When combined with "-top, -left, -right, or -bottom", it specifies the distance the element should be from other elements
padding
Same as a margin, but it specifies the distance the content of the element should be from its borders (works without using the border declaration too)
text-decoration
Adds decoration to the text, such as an underline
width
Sets the width of the element, used with height.
