Github Setup

This part will teach you how to set up your github account and start making projects!



When starting to code, I reccomend making a Github account in order to be able to save your code online for free. Furthermore, you can make your code public using github and allow other people online to view it!

This website is being displayed by github and their services right now without me having to pay a dime!


Step 1: Create your account

The first step in creating your Github account is to go to the official github website: https://github.com and click the "Sign up" button on the top right of the website. After clicking the button, you are to proceed and input your personal email and other required information in order to sucessfully create an account

Step 2: Create a Repository

Placeholder

After creating your account, you will be granted the ability to freely create github repositories. Repositories are an important part of github as they are the place where your code lives in the github platform. To view your repositories. Click on your profile picture on the top right of the Github website and select the "Repositories" option.


After selecting the "Repositories" option in the drop-down menu, you should be presented with a webpage that displays all your current repositories (it is fine and expected if you do not have any yet). To create a new repository, click the green "New" button near the top right of the website. After being redirected to a repository creation page, choose a name for your repository (should not be too long), and write a short description for it. It is reccomended to include the "Readme.md" file by selecting the "Add README" optio.

Step 3: Commit to your repository

Placeholder

To add code to your repository, you need to commit it to your repository. This part of the tutorial will be only for the Github Codespaces editor, as it is the one I mainly use (search the internet for how to commit your code if you use other editors). After writing your code in the Codespaces editor, you will have an option to commit the changes by clicking the third button on the top left of the editor. To commit the chcanges, write a short summary of what was changed and click the green "Commit" button. This will update the code everyone online can see on your repository.
