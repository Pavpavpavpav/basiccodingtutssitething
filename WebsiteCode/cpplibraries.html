Cpp Libraries

This part will teach you useful cpp (c++) libraries that you will find useful when writing your first c++ program



Cpp libraries provide a list of Statements you can use while coding that the compiler compiles into machine code for the computer to understand/do, there is a vast number of them, but this guide will only go over the most essential ones and their features

Your compiler comes with the entire standard library of these statements pre-installed, so do not worry, you do not need to install anything additional.

Use "using namespace std;" in your cpp code as a beginner to avoid writing "std::" next to a lot of functions, even though it might pose problems in profesional real world software-engineering

All the libraries are included using #include <[all lowercase name of the library]>


Included Statements

Some key statements/keywords are built-in into the programming language. Some of which include:


int [variablename]
Initializes a variable that contains numbers up to the 32-bit limit
long long [variablename]
Initializes a variable that contains numbers up to the 64-bit limit
char [variablename]
Initializes a variable that contains a single character
for ([initialization], [condition], [update]) {(code to run)}
Repeats an action that is initialized until it meets a condition (condition is false). Updates the action (such as the value of an variable) every loop
while ([condition]){(code to run)}
Repeats an action until a condition is met
return [value]
Exits a function and sends a value back to whatever called the function. If in the main() function, stops the program


Iostream

The iostream library allows for the output and input of data, even while c++ has built-in statements, these are safer and easier to use for beginners


cout << [output]
Outputs whatever is after the double <. The output can be a variable, or be put in "exclamation marks" to output text without assigning it to a string. Multiple outputs can be chained within one command if they are seperated with the double <. If the output is endl, the current line is stopped and the output continues in a new line
cin >> variable
Inputs whatever is after the double >. The variable that comes after the double > is assigned whatever the input is. Multiple inputs can be chained within the same command if they are seperated by double >.
cin.get()
A version of cin (the input statement) that waits for input before continuing the program.


String

The string library provides access to statements that manages a dynamic sequence of characters (char).


string [variablename]
Initializes a variable that contains a series of characters(char), can store words and sentences.
[stringname].size()
Returns the number of characters the string has to the caller of the function.
[stringname].push_back('[char]')
Adds a single character to the end of the string
[stringname][i]
Accesses the character that is at the i position of the string


Vector

The vector library provides access to statements that add resizable, dynamic array that stores elements in a continous memory locations, allowing for efficient access.


vector<variable type> [vectorname]
Initializes a resizable array that can be assigned values
[vectorname][i]
Accesses the item at the i position of the vector
[vectorname].size()
Returns the amount of the items stored in the vector as a value


Random

The random library provides access to statements that can allow for random values. Useful when you need a random number for a game


random_device [randomdevice name]
Used once at the start to request a random seed from the system to base its random numbers on.
mt19937 [enginename([randomdevice name]())]
A recommended engine for random numbers due to its quality and speed
uniform_int_distribution<int> [distribution name](min, max)
Allows for the calling of a random number between the min and max values
[distribution name]([engine name])
Returns a random number from the min and max of the distribution it is calling.


Cmath

The cmath library provides statements that allow for more complicated math than just addition, subtraction, division, and multiplication/


pow(x, exponent)
Raises a number x to an exponent and returns the value
sqrt(x)
Returns the square root of the number x
cbrt(x)
Returns the cube root of the number x
ceil(x)
Rounds up x to the nearest integer (whole number)
floor(x)
Rounds down x to the nearest integer
round(x)
Rounds x to the nearest integer
abs(x)
Returns the absolute vaalue of x
sin(x)
Returns the sine in radians of x
cos(x)
Returns the cosine in radians of x
tan(x)
Returns the tangent in radians of x
log(x)
Returns the logarithm of x
