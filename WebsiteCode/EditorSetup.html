Editor Setup

This part will teach you how to set up an editor so you can start coding!



A code editor is the tool that programmers use to write, edit and test their code. This section of the tutorial focuses on helping you install an editor that has all of those capabilities in order for you to be able to code easily.


How do I pick my editor?

There is a various amount of code editors available online, but the choice you make mostly depends on your prefrence. This tutorial will focus on the Editor "Visual Studio Code" as it is my editor of choice and is easy for beginners to learn



Option 1: Visual Studio Code

Visual Studio Code is a code editor with the capability to write a numerous amount of programming languages. It is compatible with Windows, Mac and Linux operating systems, but for the purpose of this tutorial, it is focusing on the windows operating system (as I do not own machines that run other operating systems)


To install Visual Studio Code on your machine (Personal Computer or Laptop), you should go to the official download website for Visual Studio code: code.visualstudio.com and click the download button. After downloading the editor, proceed by creating a new project, where you should be able to start coding by creating a new file in the editor. If your programming launguage requires an extension in order to be edited with Visual Studio Code, download it using the extensions section (There will be a tutorial for doing so for C++ as the language requires an extension)

Option 2: Github Codespaces

If you have set up your Github Account and a repository for your code/project using the Github Setup Tutorial, you can use the Github Codespaces editor to code onlne from almost any device! The Github Codespace editor is essentialy just an onine version of the Visual Studio Code editor.


Placeholder

To access the codespace for your repository, navigate to your repository (Look into the Github Tutorial). After navigating to your repository, click the green "Code" button and select the "Codespaces" option instead of the "Local" option and create a new codespace.


After creating the Codespace, you can access it on any device by repeating the steps from above but instead selecting the already existing Codespace instead of making a new one. To start coding, you can create a new file in the Explorer section of the editor, and start writing your code if it does not require an extension (Same as in the VS Code editor). If an extension is required to code in your programming language of choice, you can download it in the extension section of the editor.
