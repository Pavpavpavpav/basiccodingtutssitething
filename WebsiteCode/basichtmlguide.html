Basic HTML

This part will teach you how to create basic HTML websites and deploy them using github



HTML, or HyperText Markup Language, is the basis of almost all websites on the World Wide Web. This programming language is used to create websites, like this one, that can be displayed by browsers on any device.

This website was written in HTML and styled using CSS (more on that later)!

HTML Tags:

The HTML coding language functions using objects called "tags" that encompass your content on the website. They start with <inputtaghere> and must end with </inputsametaghere> or else problems might occur

The following tags are most commonly used to create websites:

The <html> tag
Is used to start and end a HTML document, the tag must be used only once at the start and at the end of the document
The <head> tag
Is used to include important data about the website (such as the title or links to other documents).
The <title> tag
Is used to set the title of the website tab, on this page: "Basic HTML guide - Pav's coding guide"
The <body>
Encompasses the main content of the website once
The <h1>, <h2>... tags
Headings of the Website, big text, decreasing in size from h1 to h6
The <p> tag
Short for paragraph, text of moderate/small size, automatically is put in its own line
The <br> tag
Breaks a line and adds a space between lines, useful for seperating sections
The <div> tag
Groups HTML elements together and is useful with CSS styling, the sidebar on this website is seperated with a <div> tag from the rest of the website's content and allows it to be in a fixed position on the left
The <a> tag
Links to other html pages on the website or outside websites, the link is placed inside the <a> tag in this manner: <a href="link">Text that leads to the link</a>
The <img> tag
Used to display images on the website. Does not need a closing tag. Used in this format: <img src="link to the file of the image">
The <i> tag
Makes the text italic
The <b> tag
Makes the text bold
The <dl> tag
Creates a list like this, with <dt> tag making the title of a segment in the list, and <dd> being its description
