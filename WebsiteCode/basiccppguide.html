Basic C++

This part of the guide will teach you how to create basic C++ programs and convert them into runnable executables



C++ is a high-speed programming language that was developed in 1985 as an extension of the C programming language. Since then it has been updated multiple times with the addition of new libraries (Such as C++ 11 and C++ 26). It can be used for both Console and GUI applications, but this guide will focus on Console Applications.


Editor Setup

To create a C++ file, you must see if your editor natively supports c++ as one of its coding language. If you are using Visual Studio Code, the editor the Editor Setup guide recommends, you need to install the c/c++ extension from Microsoft.


In order to create the file after downloading the extension, you must create a new file using the explorer of the editor and end it with .cpp . After creating the file, you should copy and paste the code from below as a starting point for your program.

Placeholder



            #include <iostream> //Adds the input/output statements, see C++ Libraries Section

            using namespace std;

            int main{
                cout << "Hello World!" << endl;
                return 0;
            }

When compiled into a program and ran, the code should output: 

Hello World!
